Kriteria Lulus Cetak

1. Header
Logo tidak pecah, judul terlihat, warna navy–emas tetap keluar di PDF.
2. Ringkasan
Card angka utama tidak terpotong dan bisa dibaca cepat.
3. Tabel
Header tabel muncul di halaman berikutnya, kolom tidak terlalu sempit, teks tidak saling menimpa.
4. Badge
Status hijau/kuning/merah/biru tetap jelas saat print.
5. Panjang Report
Report tidak memanjang tanpa arah. Halaman pecah wajar, bukan potong di tengah card penting.
6. Owner Readability
Angka utama cukup besar; detail tetap ada, tapi tidak membuat pembaca tua pusing.

Keputusan Praktis

Jika tabel terlalu kecil: buat mode ringkas owner dan lampiran detail terpisah. Jika terlalu panjang: pecah per section atau per modul. Jika warna tidak keluar: aktifkan Background Graphics saat print PDF. Jika HP berbeda dari laptop: jadikan laptop sebagai standar final PDF owner, HP untuk preview cepat.
