Strengths

Kekuatan

  • Modul kerja sudah luas: produksi, gudang, cukai, DO/SJ, piutang, SDM, report.
  • Executive Hub, mobile compact, dan print standard sudah mulai menyatu.
  • CK4C diarahkan benar: berbasis verpack/barang jadi, bukan giling mentah.
  • Dashboard Ringkas dan Status Hari Ini menjadi pintu baca ringan.
Weaknesses

Kelemahan

  • Halaman utama masih terlalu banyak shortcut lama sehingga belum sepenuhnya fokus.
  • Beberapa sumber data masih status valid awal dan perlu bukti final.
  • DO/SJ dan Piutang masih bergantung pada modul index lama.
  • Risiko admin bingung jika semua menu ditampilkan tanpa prioritas.
Opportunities

Peluang

  • SWOT bisa menjadi halaman utama untuk owner melihat kondisi pabrik secara cepat.
  • SDM borongan dapat dipakai untuk pembinaan produktivitas berbasis data.
  • Print report premium bisa menjadi standar komunikasi ke owner/mandor/admin.
  • Manifest navigasi bisa menjadi dasar membuat menu dinamis yang lebih bersih.
Threats

Ancaman

  • Data ganda DO/SJ atau pembayaran bisa mengganggu keputusan piutang.
  • Jika validasi cukai tidak disiplin, saldo pita/CK4C bisa salah baca.
  • Menu terlalu banyak dapat membuat admin kembali ke cara manual.
  • Report yang terlalu detail bisa membuat owner sulit menangkap keputusan.

Keputusan Desain

Konsep final: halaman utama ideal BAL-99 tidak hanya menjadi daftar modul, tetapi menjadi peta keputusan. SWOT Overview menjadi layar seni-strategis: ringkas untuk owner, cukup detail untuk admin, dan tetap aman karena tidak mengubah data. Langkah berikutnya: masukkan akses SWOT ke manifest dan navigasi, lalu uji dari HP/laptop.
